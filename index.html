Panduan Setup Google Cloud Console

  1. 1. Buka console.cloud.google.com
  2. 2. Buat project baru atau pilih project yang ada
  3. 3. Aktifkan Google Drive API

  5. 5. Tambahkan URL halaman ini ke Authorized JavaScript origins
  6. 6. Salin Client ID dan paste di atas
